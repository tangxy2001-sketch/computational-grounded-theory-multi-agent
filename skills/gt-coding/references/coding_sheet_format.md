# 编码工作表格式规范

本文档定义了扎根理论编码过程中使用的Excel工作表结构。生成表格时，如有 xlsx skill 可用，读取其 SKILL.md 并遵循其规范。

## 工作表1：初始编码表（Initial Coding）

| 列名 | 说明 | 示例 |
|------|------|------|
| **数据ID** | 笔记/文本的唯一标识符 | DATA-T3-042 (数据-主题簇3-第42条) |
| **主题簇** | 来源的BERTopic主题簇编号 | Topic_3 |
| **原文片段** | 被编码的数据片段原文 | "我每天都要..." |
| **意义单元** | 对片段的简要概括（非编码） | 描述日常使用习惯和时间投入 |
| **初始编码** | 动名词形式的编码 | 嵌入日常节奏 |
| **编码类型** | in vivo / 过程编码 / 描述编码 | in vivo |
| **分析性说明** | 为什么给出这个编码 | 参与者将使用描述为自然嵌入的日常行为... |
| **替代编码** | 可能的其他编码方向 | 构建信息习惯 |
| **关联研究问题** | 该编码主要关联的研究问题 | RQ1 |
| **编码者** | 研究者 / Claude / 共同讨论 | 共同讨论 |
| **日期** | 编码日期 | 2026-02-07 |

## 工作表2：聚焦编码表（Focused Coding）

| 列名 | 说明 | 示例 |
|------|------|------|
| **聚焦编码** | 提升后的高层编码 | 平台化的日常生活 |
| **操作性定义** | 该概念的明确定义 | 指用户将某平台使用深度整合进日常... |
| **包含的初始编码** | 归入此聚焦编码的初始编码列表 | 嵌入日常节奏; 仪式化浏览; ... |
| **支撑数据量** | 支撑该编码的数据片段数 | 23 |
| **代表性数据** | 最能说明该编码的1-2个数据片段 | "每天早上醒来第一件事..." |
| **负面案例** | 不符合该编码的反例 | 有用户表示刻意控制使用时间... |
| **备忘录链接** | 相关备忘录编号 | MEMO-FC-003 |
| **关联研究问题** | 该聚焦编码主要关联的研究问题 | RQ1 |

## 工作表3：概念范畴表（Categories）

| 列名 | 说明 | 示例 |
|------|------|------|
| **范畴名称** | 理论层面的概念范畴 | 数字亲密性的建构 |
| **定义** | 范畴的理论性定义 | 用户通过平台互动建构一种... |
| **维度/属性** | 该范畴的关键维度 | 强度(高-低), 方向(主动-被动)... |
| **包含的聚焦编码** | 归入此范畴的聚焦编码 | 平台化的日常生活; 情感投射; ... |
| **与其他范畴的关系** | 因果/条件/策略等关系 | → 导致"身份协商" |
| **理论饱和度** | 低/中/高 + 说明 | 中 — 需要更多负面案例 |
| **关联研究问题** | 该范畴主要回应的研究问题 | RQ1 & RQ2 |

## 工作表4：分析追踪表（Audit Trail）

| 列名 | 说明 |
|------|------|
| **日期** | 分析活动日期 |
| **活动类型** | 编码 / 备忘录 / 文献阅读 / 理论讨论 / 理论抽样 |
| **描述** | 具体做了什么 |
| **决策与理由** | 做了什么分析决策、为什么 |
| **涌现的问题** | 过程中产生的新问题 |

此追踪表同时服务于研究的可审计性（auditability），是定性研究质量保障的重要组成部分。

## 命名约定

- **数据ID**: `DATA-T{主题簇号}-{序号}` 例如 `DATA-T3-042`
- **备忘录ID**: `MEMO-{类型缩写}-{序号}` 例如 `MEMO-TC-001`（TC=理论编码, IC=初始编码, PR=过程, LIT=文献）
- **聚焦编码ID**: `FC-{序号}` 例如 `FC-012`
- **范畴ID**: `CAT-{序号}` 例如 `CAT-005`
