# 对话日志格式

## 目的

对话日志记录研究者与Claude Code在编码会话中的互动过程。它是反思性备忘录的核心素材之一，保存了那些不会进入编码表或常规备忘录的过程细节：试探性的想法、被放弃的方向、分歧与妥协、被忽略的建议。

## 生成方式

在每次编码会话结束时，研究者对Claude Code说：

```
请将我们这次会话的对话导出为日志，保存到 logs/ 目录
```

Claude Code 将对话整理为以下格式的 Markdown 文件。

## 文件格式

```markdown
# 对话日志：{主题描述}

- **日期**: YYYY-MM-DD
- **会话时长**: [大约时长]
- **研究阶段**: [初始编码 / 聚焦编码 / 理论建构 / ...]
- **处理的数据**: [主题簇编号、数据条数等]

## 会话摘要

[2-3句话概括这次会话做了什么、产出了什么]

## 关键对话片段

[不需要记录每一句话。重点记录以下类型的交互：]

### 片段1：[标签，如"编码分歧""意外发现""概念碰撞"]

**语境**：[这段对话发生的背景]

> **研究者**：...
> **Claude**：...
> **研究者**：...
> **Claude**：...

**结果**：[这段对话最终导向了什么——一个编码？一个备忘录？一个未解决的分歧？]

### 片段2：[标签]
...

## 分析决策记录

[本次会话中做出的重要分析决策]

| 决策 | 谁先提出 | 讨论过程 | 最终结果 |
|------|----------|----------|----------|
| [决策描述] | Claude建议 / 研究者提出 | [简要讨论] | [结果] |

## Claude的建议中被采纳的

[列出本次会话中被采纳的Claude建议，简要说明]

## Claude的建议中被拒绝的

[列出本次会话中被拒绝或搁置的Claude建议，简要说明拒绝理由]

## 值得后续反思的时刻

[标注几个觉得"有什么东西值得想想"但当时没时间细想的时刻]

- ...
- ...
```

## 记录原则

- **选择性记录**：不是会议记录，不需要逐字逐句。重点捕捉有分析价值的互动时刻
- **保留原始语言**：对话片段尽量保留原始措辞，包括口语化表达、犹豫、修正
- **标注情感线索**：如果对话中研究者用文字表达了情感反应，在片段旁边标注
- **记录"没有发生的事"**：如果Claude提出了一个建议而研究者没有回应就继续了下一个话题，这个"跳过"也值得记录
- **不要美化**：不要把对话整理得过于连贯和逻辑化。真实的对话是跳跃的、有时混乱的

## 文件命名

```
logs/session_YYYY-MM-DD_{主题描述}.md
```

例如：
- `logs/session_2026-02-07_topic42_初始编码.md`
- `logs/session_2026-02-10_聚焦编码_情感类编码整合.md`
